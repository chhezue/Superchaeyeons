# 하네스 동작·사용 안내 대조

README와 현재 동작 문서를 Claude·Codex의 등록 파일, 프로젝트 설정, 검사 스크립트와 대조했다. DB 스키마 변경을 예로 들어 에이전트가 절차를 고르는 시점, 사람이 승인하는 대상, 훅이 검사하는 조건을 구분했다.

| 문서 | 수정 근거 |
|---|---|

| [문서 색인](../README.md) · [산출물 등록부](../templates/README.md) | 수동 복사하는 템플릿, 프로젝트별 문서 위치, 런타임별 로컬 기록을 구분했다. 감사 색인의 스킬 이름과 참고 자료의 플러그인 경로를 고쳤다. |

## 결정

측정값과 설치 실험에는 당시 날짜와 조건을 남겼다. 계속 바뀌는 목록은 구성 요소 목록과 실행 스크립트로 연결했다.

## 실행한 검증

| 검증 | 실행한 명령 | 결과 |
|---|---|---|
| 저장소 전체 | `plugin/scripts/dev.sh test` | 9단계 통과. 문서 검사 75개 파일에서 오류 0개, 경고 115개. 로컬 포트를 사용하는 엔진 테스트와 Claude 매니페스트 검사 포함. |
| 변경 형식 | `git diff --check` | 오류 0개 |

- 독립 문서 리뷰에서 지적한 문서 루트의 예외, 삭제된 예제 링크, 사례 표의 잘못된 행 참조를 수정했다.
- 현재 안내 문서의 상대 파일 링크를 로컬 파일과 대조했다. 과거 예제를 가리키는 링크는 해당 Git 커밋에서 파일의 존재를 확인했다.
