# test-hooks.sh가 읽는 훅 케이스. 한 줄에 하나, `#`은 주석.
# 형식: 파일[ 인자…]<TAB>SCOPE<TAB>기대<TAB>stdin
#   파일: plugin/hooks/ → .claude/hooks/ → plugin/scripts/ → scripts/ 순으로 찾는다. 공백 뒤는 인자(훅은 보통 없음)
#   SCOPE: `-`면 훅 원본 그대로, 값이 있으면 훅 본문의 `SCOPE="…"` 줄을 그 값으로 바꾼 임시 복사본으로 실행.
#          `;self=0`을 붙이면 `HARNESS_SELF_EDIT="…"` 줄도 그 값으로 바꾼다 (예: `.;self=0`)
#          `;test=CMD`를 붙이면 `TEST_CMD="…"` 줄도 바꾼다 (예: `.;test=`는 빈 값). 여러 개는 `;`로 잇는다
#          `;대문자이름=값`은 본문의 `대문자이름=…` 줄을 `대문자이름="값"`으로 바꾼다. SCOPE를 두고 상수만 바꾸려면 `-;STORE=$TMP/q`
#          `;env:이름=값`은 그 실행에만 환경 변수를 준다. `;cp:원본=대상`은 실행 전에 파일·폴더를 복사한다(저장소 파일을 고치는 도구를 $TMP 복사본으로 시험할 때)
#   기대: 종료 코드, 뒤에 `;검사`를 붙일 수 있다 — `out=`(출력 없음) · `out~ERE` · `out!~ERE` · `err~ERE`(차단 메시지) · `file:경로~ERE` ·
#         `lines:경로=N`(없는 파일은 0줄) · `nofile:경로`. 열이 탭으로 갈려서 ERE의 탭은 `[[:space:]]`로 쓴다
#   stdin·인자·상수 값·검사 경로 안의 $REPO는 저장소 루트, $HOME은 홈, $TMP는 이번 실행의 임시 폴더로 치환된다.
#   $TMP는 케이스끼리 공유하므로 앞 케이스가 남긴 상태(정정 대기열 등)를 뒤 케이스가 이어서 본다
# 훅 공통 규약 — 모든 deny-* 훅은 (1) 정상 범위는 통과 (2) 위반은 exit 2 (3) 판정 불가(JSON 깨짐·키 없음·빈 입력·python3 없음)는 exit 2
# python3 없음 케이스는 PATH를 바꿔야 해서 이 파일이 아니라 test-hooks.sh 내장 케이스가 deny-* 전부에 자동으로 돌린다.
# 이 파일은 "훅이 한 번 열렸다"(baro 회고 4)를 재발 방지하는 장치다 — 새 우회 경로를 발견하면 케이스를 먼저 추가한다.
