# Harness Retro — 하네스 개선 후보

하네스(규칙·스킬·에이전트·훅)가 놓친 것과 그 조치의 효과를 적는 장부다. `improve-harness` 스킬이 회고 분석(`scripts/analyze-corrections.sh`)의 후보를 사용자와 검토한 뒤 승인된 것만 여기에 더한다. 행을 더하거나 특정 행의 값만 고치고, 표를 통째로 다시 쓰지 않는다. **코드·설계** 개선은 여기가 아니라 `core-workflow.md` G4 후속 제안이 담당한다. 회고 루프 전체는 [회고 루프 스펙](../specs/cross-cutting/harness-retro-loop.md)에 있다.

열의 값은 아래와 같다.

| 열 | 값 |

| `ID` | `R-001`부터 차례로. 분석 후보와 검토가 행을 이 값으로 가리킨다 |
| `상태` | `승인 대기 — 수정안 제시(날짜)`(장부에 올렸고 반영 승인 전) · `반영(날짜)` · `채택 안 함` · `대체됨`(다른 스펙이 같은 문제를 다른 방법으로 푼다) · `되돌림(날짜)`(효과가 없거나 해로워 조치가 더한 글을 지웠다) |
| `효과` | 반영한 조치가 이후 세션에서 실수를 실제로 줄였는지. `미확인` · `도움됨` · `해로움` · `효과 없음` · `판정 불가`. 검토 때 근거가 생길 때만 고친다. 채택하지 않았거나 대체된 행은 `—` |
