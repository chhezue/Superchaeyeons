# Core — 멈추는 근거

`core-guardrails.md` §1.4 "불확실하면 질문"을 재현 가능한 신호로 바꾼 것이다. 멈추는 이유는 표현이 모호해서가 아니라 **변경이 통제 영역에 닿기 때문**이다 — 그래야 판정이 재현되고, 위임 영역에서는 덜 묻는다. 모든 것에서 멈추면 그 멈춤은 곧 무시된다.

## 1. 통제 영역과 위임 영역

변경이 왼쪽 열에 닿으면 트랙·규모와 무관하게 G2 승인 대상이다. 오른쪽 열만 건드리면 G2를 짧게 지나가고 G3 검증에 무게를 둔다. 두 열에 걸치면 통제 쪽으로 본다.

| 통제 — G2 승인 없이 구현하지 않는다 | 위임 — 계약과 테스트로 검증한다 |
|---|---|
| 도메인 규칙 · 비즈니스 흐름 · 상태 전이 | 멱등하게 테스트 가능한 컴포넌트 |
| 인증 · 과금 · 개인정보 | 표현 계층 구성 |
| 장애 복구 · 재시도 · 멱등성 | 매핑·변환 계층 |
| 외부 API 계약 · 스키마 · 마이그레이션 | 반복적인 상용구 · 문서 초안 |

## 2. 멈추는 신호

1번에 걸리지 않아도 하나라도 해당하면 구현 전에 확인한다.

| 신호 | 대응 |
|------|------|
| 사용자가 정하지 않은 **기본값**(TTL · 페이지 크기 · 재시도 횟수 · 타임아웃 · 파일 위치)을 골라야 함 | 후보와 권장 값을 보이고 묻는다 |
| **열린 표현**("알아서"·"적당히"·"최적화"·"개선해줘"·"정리해줘")이나 해석이 갈리는 범위. Approved 스펙이 있거나 사용자가 "질문 없이 진행"이라고 했으면 제외 | `ask` 스킬 — 결정만 라운드로 묻는다 |
| 새 파일 3개 이상 · 파일 삭제 · **의존성 추가**(서드파티 플러그인 설치 포함) | 목록을 먼저 보이고 승인 |
| 문서 2개가 다른 값을 말함 | `core-guardrails.md` §1 |
| **트랙이 바뀜** — B 중 계약·기술 변경이 필요해짐 | A 승격 여부를 묻는다 |
| **훅이 막음** | 3절 — 우회하지 않고 보고한다 |

**의존성 사다리:** 새 의존성 전에 표준 라이브러리 → 플랫폼 기본 기능 → 이미 설치된 의존성 → 직접 작성 순으로 먼저 밟는다. 서드파티 도구는 `{{문서 루트}}/out-of-scope/README.md`(있으면)에서 이미 기각된 것인지 먼저 본다.

## 3. 자동으로 하지 않는 것

조건은 각 근거 파일이 갖는다.

| 하지 않는다 | 근거 |
|------|------|
| 커밋 실행 · 이슈·브랜치·PR 생성 (승인·명시 요청 없이) | `core-workflow.md` G4 |
| `[미정]` 확정 · 우선순위 라벨 부여·변경 | `core-guardrails.md` §1.8 |
| `.claude/rules/` 추가·수정 — 제안만 | `core-workflow.md` G4 · `retro` 스킬 |
| `{{작업 범위}}` 밖 파일 수정 | `deny-out-of-scope-write.sh` (상수 `SCOPE` = 이 슬롯 값) |
| **[플래그: 하네스 자기 수정]** ❌면 `.claude/hooks/`·`settings.json` 수정 — 훅은 Write·Edit 계열 도구만 막으므로 Bash 편집도 하지 않는다. ☑이어도 diff를 제안하고 승인 뒤 반영 | `deny-out-of-scope-write.sh` (상수 `HARNESS_SELF_EDIT`) |
| 훅이 막은 것을 다른 도구(`Bash` 포함)로 우회 · 통과시키려고 훅·`settings.json`을 고치기 | 이 절 |
| `{{테스트 명령}}`을 돌리지 않고 완료·통과 선언 | `core-workflow.md` G3 · `deny-unverified-completion.sh` |

**훅 승인 통로는 설정 변경뿐이다.** 훅은 사용자의 구두 승인을 모른다. 알게 만들면(환경 변수·마커 파일) 그 통로를 에이전트도 열 수 있어 결정론이 무너진다. 승인은 사용자가 `harness-map.md`의 슬롯·플래그 값과 짝인 훅 상수를 바꾸거나 그 파일을 직접 고치는 것이다. 에이전트는 막힌 사실과 이유, 사용자가 무엇을 바꾸면 되는지를 한 줄로 보고하고 멈춘다. 채팅으로 하는 G2 승인(스펙·감사 항목·원인 가설)은 이 절의 대상이 아니다.
