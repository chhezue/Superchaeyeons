# Adopt — 하네스를 프로젝트에 붙이는 유일한 경로

**이 스킬이 기본 동작과 다른 단 하나:** 축·슬롯·형식 값을 **물려받지 않고 저장소에서 실측한다.** 하네스 배달본의 기본값은 그린필드용이고, 기존 저장소에서는 실측이 기본값을 덮어쓴다.

**이 스킬은 `core-workflow.md` 사이클의 D 트랙이다.** 실측이 진입, 제안이 **G2 승인**, 채움 뒤 `scripts/check-portability.sh`와 아래 산출물 체크리스트가 **G3 검증**이다. Invariant(작업 내내 참이어야 하는 것): **애플리케이션 코드를 한 줄도 바꾸지 않는다** — 산출물은 `harness-map.md` 값·`local-*.md`·`AGENTS.md`뿐이다.

## When to Use

- 하네스(`.claude/` 등)를 새 저장소에 복사한 직후 — 그린필드도 이 경로로 들어온다. 신규 저장소는 1·4단계가 짧아질 뿐이다
- **재동기화:** 문서 위치·빌드 명령·커밋 관례 등 프로젝트 사실이 바뀌어 `harness-map.md` 값이 실제와 다를 때. 1단계를 다시 돌려 현재 값과 실측의 diff 표를 만들고 승인 후 갱신한다

**생략 불가:** "앞의 프로젝트와 비슷하니 그 값을 쓰자"는 이 스킬을 깨뜨리는 것이다. 커밋 형식을 물려받았다가 963개 커밋을 세어보고서야 실제 관례가 다르다는 걸 안 사례가 계기다.

## Steps

### 1. 실측 — 사람을 기다리지 않는다

`{{작업 범위}}`(기본 `.`) 안에서 아래를 코드·이력으로 확인한다. `scripts/adopt-probe.sh [저장소] [범위]`가 이 표의 대부분을 한 번에 뽑아 준다 — 출력을 그대로 2단계 제안의 근거로 붙이고, 사람이 확인해야 할 항목(운영 데이터 보존·Git 컨벤션 파일을 둘 권한·외부 클라이언트 계획)만 질문으로 남긴다. 각 항목은 **사실 + 근거(명령 또는 파일)** 로 표에 적는다. 사람에게 물을 것은 이 단계에서 나오지 않는다 — 환경이 답할 수 있는 것은 직접 본다.

| 축 | 확인할 것 | 근거를 얻는 방법 (예) |
|----|-----------|----------------------|
| **lang** | 언어·프레임워크·버전, 빌드·테스트·포맷·의존성 조회 명령, 정적 검사 도구, 리뷰어 후보 | 빌드 선언 파일(`build.gradle*`·`pom.xml`·`package.json`·`pyproject.toml`·`go.mod` 등) · 확장자별 파일 수 `git ls-files \| sed 's/.*\.//' \| sort \| uniq -c` · CI 워크플로의 실제 명령 (다스택 예시) |
| **shape** | 저장소 루트 vs 하위 경로, 문서 루트, `.github/`에 파일을 둘 수 있는가(소유권), 모듈 경계, **커밋·브랜치 형식** | `git log --format=%s`를 패턴별로 집계 · `git branch -r` 이름 패턴 · 기존 `CONTRIBUTING`·`docs/` 위치 · 모노레포면 하위 패키지 목록 (다스택 예시) |
| **deploy** | 외부 클라이언트 유무(앱·별도 프론트), 인증 위치(게이트웨이·앱), 배포 SSOT 파일 | `deploy/`·`docker-compose*`·`k8s/`·`.github/workflows/` · OpenAPI export 흔적 · 클라이언트 저장소 참조 (다스택 예시) |
| **stage** | 운영 보존 데이터 유무, 마이그레이션 파일 존재, 기능 완성도(커밋 수·릴리즈 태그), 계약 동결 여부 | 마이그레이션 파일(`V*__*.sql` 등) `find` · `git tag` · 커밋 수 · 운영 환경 설정 유무 |

**슬롯 후보**도 같은 표에서 나온다 — 스펙 폴더·결정 기록·감사 로그·용어집·제품 범위 문서가 실제로 어디 있는지, 없으면 `(없음)`으로.

### 2. 축·슬롯·플래그 제안 → **승인 (G2)**

실측표를 근거로 `harness-map.md`의 **축 4행 · 슬롯 전부 · 플래그 7행**을 채운 제안을 만든다. 형식은 `harness-map.md`의 표 그대로이고, 각 행에 근거를 한 줄 붙인다.

- 실측으로 정해지지 않는 값(운영 데이터를 앞으로 보존할 것인가, 외부 클라이언트를 붙일 계획인가 등)은 **질문으로** 낸다. 질문은 번호를 붙이고 권장 답을 함께 적는다 — 사람이 번호로 답할 수 있게
- `(없음)`과 ⬜는 "아직 모름"이 아니라 "이 프로젝트엔 그 개념이 없음"일 때만 남기고, 그 뜻을 값 칸에 적는다
- **사용자 승인 없이 3단계로 넘어가지 않는다**

### 3. 채움 → **승인 (G3)**

승인된 값으로 아래를 만든다. `core-*.md`는 손대지 않는다 (`harness-map.md` 규칙 5).

1. `harness-map.md` — 축·슬롯·플래그 값. 플래그 ❌면 해당 훅을 `.claude/settings.json`에서 해제 (규칙 절은 지우지 않는다)
2. **lang 팩** — `.claude/`에는 스택 파일이 없다. 실측한 lang 축에 맞는 씨앗이 `examples/seeds/{스택}/`에 있으면 그 README의 "무엇을 어디에 복사하나" 표대로 복사하고, 없으면 `examples/seeds/_template/`을 복사해 실측값으로 채운다. **파일명의 `local-` 접두사를 떼지 않는다** — `scripts/check-portability.sh`가 그 접두사로 local 층을 식별해 검사에서 빼므로, 접두사가 빠지면 복사 직후부터 검사기와 pre-commit이 막힌다. **복사한 씨앗은 즉시 대조한다** — 씨앗 README의 "씨앗 대조" 표에 있는 전제(의존성·버전·기반 클래스·표기 방식)마다 빌드 파일·코드를 열어 확인하고, 다르면 씨앗 본문을 고치고 근거 파일을 표에 적는다. 확인하지 않은 전제를 남기지 않는다 — 검증 없이 물려받은 전제가 같은 실수를 세 번 낳은 사례가 계기다. 씨앗 훅은 해당 플래그가 ☑일 때만 `.claude/hooks/`로 복사하고 `settings.json`에 등록한다
3. `local-*.md` — 슬롯으로도 플래그로도 안 빠지는 **그 저장소만의 사실**이 있을 때만. `AGENTS.md`와 중복이면 만들지 않는다
4. `AGENTS.template.md` → `AGENTS.md` 채움 · `./scripts/install-git-hooks.sh` · `commit-msg` 훅 정규식이 `{{커밋 메시지 형식}}`과 일치하는지 확인

**산출물 체크리스트** — 전부 통과해야 완료다. `pack.md` 계약 대신 이 목록이 생성물 품질을 지킨다.

- [ ] `scripts/check-portability.sh` exit 0 (core가 순수한 채로 남았다)
- [ ] `harness-map.md`에 `(없음)`·⬜가 없거나, 남은 것마다 "이 프로젝트엔 없음"이라는 이유가 값 칸에 있다
- [ ] "스택 팩" 표의 파일 목록 = 실제 `.claude/rules/`·`.claude/agents/` 파일
- [ ] 복사한 씨앗의 "씨앗 대조" 표에 빈 칸이 없다 (전제마다 근거 파일)
- [ ] `{{문서 루트}}/templates/README.md` 산출물 등록부의 "프로젝트 문서" 행이 이 저장소 값으로 채워졌다
- [ ] `settings.json`의 훅 등록 상태 = 플래그 ☑/❌
- [ ] `AGENTS.md`에 `{…}` 자리표시자가 0개
- [ ] `{{커밋 메시지 형식}}`이 최근 커밋 20개와 일치한다 (`git log -20 --format=%s`)

### 4. 역스펙·초기 백로그 (기존 코드가 있을 때) → **승인 (G2 — Draft 스펙·감사 후보 목록)**

기능이 이미 완성된 저장소라면 하네스가 처음부터 있었던 것처럼 문서를 갖춘다 — **구현하지 않는다.**

- 주요 도메인의 **현재 동작**을 `{{스펙 저장소}}`에 Draft 스펙으로 (상태 `Implemented`·`Draft(역스펙)` 표기)
- 감사 후보를 `{{감사 로그}}`에 남긴다 — 실제 감사·리팩터는 `safe-refactor`(B 트랙)가 승인 후 진행

`core-reporting.md` 문체로 짧게: 축 4개 값, 채운 슬롯 수와 남긴 `(없음)` 수, 켠 플래그, 지운 스택 팩, 만든 `local-*.md`, 체크리스트 결과.

## 금지

- 실측 없이 기본값이나 다른 프로젝트 값을 채움
- 승인 전에 `harness-map.md`·`local-*.md`를 쓰기 시작함
- `core-*.md` 수정 · 애플리케이션 코드 수정
- `(없음)`·⬜를 이유 없이 남기고 완료 선언

## It's working if

- `harness-map.md`를 열지 않아도 `scripts/check-portability.sh`가 exit 0이고 pre-commit이 통과한다
- 새 세션에서 에이전트가 `{{테스트 명령}}`을 물어보지 않고 바로 실행한다
- 커밋 메시지가 저장소의 기존 관례와 같은 모양으로 나온다
