# Product — 기획

제품 범위·용어·비즈니스 규칙을 두는 폴더다. 하네스는 아래 슬롯으로 이 내용을 부른다. 이 저장소는 애플리케이션이 없는 하네스 템플릿이라 지금은 이 폴더에 기획 문서가 없고, 슬롯 값은 `.claude/rules/harness-map.md`와 같다.

| 슬롯 | 이 저장소의 값 |
|------|-----------|
| `{{제품 범위}}` | `AGENTS.md` — "무엇이 들어 있나"·"이 저장소에서 작업할 때" |
| `{{우선순위 SSOT}}` | (없음) — 이슈 우선순위 라벨 체계가 없다 |
| `{{클라이언트 전제}}` | (없음) — 클라이언트 없음 |
| `{{용어집}}` | (없음) — 하네스 용어는 `harness-map.md`와 `core-workflow.md`가 정의 |

이 폴더에 기획 문서를 만들면 `.claude/rules/harness-map.md`의 해당 행을 같은 턴에 그 경로로 바꾼다.
