# Reports — 작업 보고서

계약·데이터·여러 구성 요소에 영향을 주는 L 작업에서 기존 기록에 담기 어려운 검증 결과를 보관한다. `{{문서 루트}}/reports/` 슬롯 기본값. 파일명 `{YYYY-MM-DD}-{kebab-topic}.md`, 골격은 [`templates/reference-doc.md`](../templates/reference-doc.md) "작업 보고서" 절. **"검증하지 못한 것" 절**이 핵심이다 — 환경이 없어 못 돌린 검증은 실패가 아니라 여기에 남기는 것이 정상 경로다.

[설치 후 테스트와 작업당 토큰 측정](2026-11-24-harness-task-cost.md)은 Claude·Codex의 시작 지시 분량과 합성 작업의 모델 사용량을 비교한다.
